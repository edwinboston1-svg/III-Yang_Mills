# THE PROOF — THE CODE AND THE KERNEL, IN THE STEPS' ORDER

Every file below is a copy of the instrument or kernel module the step names, taken from the development's repository at the commit the step's numbers were read from; the records (the runs' outputs) stay in that repository beside the instruments and are cited by the step. The copies carry the mathematics and the known answers; an identifier naming a working session or a person has been removed from a comment where one occurred, nothing else changed.
